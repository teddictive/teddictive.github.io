# teddictive.com 사이트 사용설명서

이 폴더 하나에 사이트 전체가 들어 있습니다. 페이지, 이미지, 글꼴, 디자인, 동작, 그리고 수정 도구까지 모두 여기 있습니다.
사이트 주소는 **https://teddictive.com** 입니다. GitHub 저장소는 `github.com/teddictive/teddictive.github.io` 입니다.

일하는 순서는 늘 같습니다.

> **① 이 폴더에서 고친다 → ② `미리보기.command`로 확인한다 → ③ `사이트에 올리기.command`로 올린다 (1~2분 뒤 반영)**

---

## 0. 폴더 안 내용

| 이름 | 무엇인가 |
|---|---|
| `index.html` | 첫 화면(홈) |
| `작품주소.html` | 작품 페이지 하나에 파일 하나. 예) `Hypertaste-2016.html` → teddictive.com/Hypertaste-2016.html |
| `Information.html` | CV 페이지 |
| `404.html` | 없는 주소로 들어왔을 때 나오는 페이지 |
| `images/` | 모든 이미지 |
| `css/` `fonts/` `js/` | 디자인, 글꼴, 동작(확대 보기, 페이지 전환 등). 보통은 건드리지 않습니다 |
| `새페이지/` | 새 작품 페이지 재료를 넣는 곳. 인터넷에는 올라가지 않습니다 |
| `tools/add_page.py` | 새 페이지를 만들어 주는 도구 |
| `미리보기.command` | 더블클릭하면 내 컴퓨터에서 사이트를 띄웁니다 |
| `사이트에 올리기.command` | 더블클릭하면 바뀐 내용을 인터넷에 올립니다 |
| `새 페이지 만들기.command` | 더블클릭하면 `새페이지/` 안의 재료로 페이지를 만듭니다 |
| `CNAME` | teddictive.com 도메인 연결 정보. **지우지 마세요** |
| `_source/` | 처음 Cargo에서 가져온 원본 데이터(백업용). 인터넷에는 올라가지 않습니다 |

> 처음 `.command` 파일을 더블클릭하면 "확인되지 않은 개발자" 경고가 뜰 수 있습니다. 그때는 파일을 **우클릭 → 열기 → 열기**로 한 번 열어 주세요. 다음부터는 더블클릭으로 열립니다.

## 1. 미리보기 (올리기 전에 확인)

1. `미리보기.command`를 더블클릭합니다.
2. 브라우저에 `http://127.0.0.1:8770/` 이 열립니다. 실제 사이트와 똑같이 동작합니다.
3. 파일을 고친 뒤에는 브라우저에서 **새로고침(⌘R)** 하면 바뀐 내용이 보입니다.
4. 다 봤으면 터미널 창을 닫습니다.

## 2. 새 작품 페이지 만들기 (가장 쉬운 방법)

### ① 재료 폴더 만들기
`새페이지/` 안에 폴더를 하나 만듭니다. 이름은 아무거나 괜찮습니다(예: `새페이지/조명작업/`).
`새페이지/_예시/` 폴더를 복사해서 시작하면 편합니다.

그 폴더에 아래 파일들을 넣습니다.

**`info.txt`** — 페이지 기본 정보입니다. 콜론(:) 뒤만 바꾸세요.
```
주소: My-New-Work-2026
제목: My New Work (2026)
메뉴이름: My New Work
위치: Silicon-Intelligence-2020
```
- **주소**: 인터넷 주소가 됩니다(`teddictive.com/My-New-Work-2026.html`). 영문, 숫자, `-`, `_`만 쓸 수 있고 띄어쓰기는 안 됩니다.
- **제목**: 홈 화면 썸네일 아래와 브라우저 탭에 보이는 이름입니다.
- **메뉴이름**: 왼쪽 메뉴에 보이는 이름입니다.
- **위치**: 이 작품의 메뉴와 썸네일을 *어느 작품 바로 앞에* 둘지 정합니다. 기존 작품 주소를 적으면 됩니다. 비워 두면 맨 앞(맨 위)에 들어갑니다.

**이미지 파일들** — jpg, png, gif. 예: `01.jpg`, `02.jpg`, `03.jpg`
- 파일 이름 순서대로 페이지 아래쪽에 나옵니다.
- 가로 2000px 안팎이 적당합니다. 너무 큰 원본(10MB 이상)은 줄여서 넣는 것을 권합니다.

**`썸네일.jpg`** (선택) — 홈 화면 격자에 보일 이미지입니다. 없으면 첫 번째 이미지를 씁니다.

**`본문.txt`** (선택) — 페이지 글입니다.
```
Material - wood, steel, LED

Size - 300 . 300 . 1200 (mm)

[이미지 01.jpg]
작품 설명을 여기에 씁니다.
[유튜브 https://www.youtube.com/watch?v=XXXXXXX]
[이미지 02.jpg]
```
- 한 줄이 화면에서도 한 줄입니다. 빈 줄은 빈 줄로 보입니다.
- `[이미지 파일이름]`을 쓰면 그 자리에 이미지가 들어갑니다. 본문에 안 쓴 이미지는 글 아래에 차례로 붙습니다.
- `[유튜브 주소]`, `[비메오 주소]`를 쓰면 그 자리에 영상이 들어갑니다.

### ② 페이지 만들기
`새 페이지 만들기.command`를 더블클릭하고, 목록에서 방금 만든 폴더 번호를 입력합니다.
(터미널에서 직접 하려면: `python3 tools/add_page.py 새페이지/조명작업`)

이 도구가 하는 일:
- `My-New-Work-2026.html` 페이지를 만듭니다.
- 이미지를 `images/`로 복사합니다.
- **모든 페이지의 왼쪽 메뉴에 링크를 추가합니다.** 이 링크가 "누르면 그 페이지로 들어가는 버튼"입니다.
- **홈 화면 썸네일 격자에도 추가합니다.** 썸네일을 눌러도 그 페이지로 들어갑니다.
- 이미지는 클릭하면 확대되고, 스크롤하면 서서히 나타나는 효과가 자동으로 적용됩니다.

### ③ 확인하고 올리기
`미리보기.command`로 확인한 뒤 `사이트에 올리기.command`를 더블클릭합니다.

> 같은 주소로 다시 만들 수는 없습니다. 고치고 싶으면 4번처럼 html을 직접 고치거나, 6번 방법으로 지우고 다시 만드세요.

## 3. 버튼(링크)이 어떻게 페이지로 연결되는지

모든 버튼은 html 안의 `<a href="...">` 한 줄입니다. 왼쪽 메뉴의 한 항목은 이렇게 생겼습니다.
```html
<a href="Hypertaste-2016.html" rel="history">Hypertaste</a><br/>
```
- `href="..."` = 눌렀을 때 갈 페이지 파일 이름
- `>Hypertaste<` = 화면에 보이는 글자
- `<br/>` = 줄바꿈

**글 중간에 링크를 넣고 싶을 때** (본문 안에서)
```html
자세한 내용은 <a href="Information.html" rel="history">CV</a>를 보세요.
외부 사이트: <a href="https://www.instagram.com/teddictive/" target="_blank">Instagram</a>
```
- 사이트 안의 페이지는 `rel="history"`를 붙입니다. 그러면 새로고침 없이 부드럽게 넘어갑니다.
- 외부 사이트는 `target="_blank"`를 붙입니다. 그러면 새 탭에서 열립니다.

> ⚠️ 왼쪽 메뉴와 홈 썸네일 격자는 **모든 html 파일 안에 똑같이 복사되어** 있습니다.
> 메뉴를 손으로 고칠 때는 모든 페이지를 똑같이 고쳐야 합니다. 텍스트 편집기의 "폴더 전체에서 찾아 바꾸기"를 쓰면 편합니다.
> 새 페이지를 추가할 때는 2번의 도구를 쓰면 이 작업이 자동으로 됩니다.

## 4. 기존 페이지의 글·이미지 고치기

html 파일은 **텍스트 편집기**로 엽니다. VS Code(무료)를 권합니다. 맥의 텍스트 편집기를 쓸 때는 *포맷 → 일반 텍스트로 만들기* 상태에서 고치세요.

페이지 본문은 `data-container="page"` 아래의 `<div class="page_content clearfix" ...>`와 그다음 `</div>` 사이에 있습니다.
에디터에서 ⌘F로 본문 첫 문장을 검색하면 바로 찾을 수 있습니다.

| 하고 싶은 것 | 이렇게 쓰기 |
|---|---|
| 줄바꿈 | 줄 끝에 `<br/>` |
| 굵게 | `<b>굵은 글</b>` |
| 작은 회색 글(고정폭) | `<small>작은 글</small>` |
| 이미지 넣기 | `<img class="image-zoom scroll-transition-fade" src="images/파일이름.jpg"/><br/>` |
| 이미지 바꾸기 | 새 이미지를 `images/`에 넣고, 해당 `<img ... src="images/...">`의 파일 이름만 바꾸기 |
| 이미지 빼기 | 그 `<img .../>` 한 줄 지우기 |
| 영상 넣기 | YouTube/Vimeo의 "공유 → 퍼가기(embed)" 코드를 그대로 붙여넣기 |

- 이미지 태그에 `class="image-zoom ..."`가 있으면 클릭했을 때 확대됩니다.
- `width`/`height` 숫자는 없어도 됩니다. 있다면 이미지 원래 크기로 맞춰 주세요.
- **홈 첫 화면 글**("TDDV : TEDDICTIVE", User/AI 대화)은 `index.html`에 있습니다.
- **CV**는 `Information.html`에 있습니다.
- **썸네일 이미지나 제목을 바꿀 때**는 모든 html 파일 안의 같은 썸네일을 똑같이 바꿔야 합니다(3번의 ⚠️ 참고). 썸네일 하나는 `<div class="thumbnail ..." data-id="...">`부터 시작합니다.

## 5. 인터넷에 올리기

`사이트에 올리기.command`를 더블클릭하면 끝입니다. 1~2분 뒤 https://teddictive.com 에 반영됩니다.

터미널에서 직접 하려면:
```
cd 이 폴더
git add -A && git commit -m "수정 내용" && git push
```
- 브라우저에 예전 화면이 보이면 ⌘⇧R(강력 새로고침)을 누르세요.
- GitHub 웹사이트에서 직접 파일을 고쳤다면, 다음 작업 전에 `git pull`로 내 폴더를 맞춰야 합니다. `사이트에 올리기.command`는 이 작업을 자동으로 먼저 합니다.

## 6. 페이지 지우기 / 메뉴 순서 바꾸기

**지우기**
1. `작품주소.html` 파일을 지웁니다.
2. 모든 html에서 그 작품의 메뉴 줄(`<a href="작품주소.html" ...>…</a><br/>`)과 썸네일 묶음(`<div class="thumbnail ..." ...>`부터 짝이 맞는 `</div>`까지)을 지웁니다.
3. 이미지는 `images/`에서 지워도 되고 그냥 둬도 됩니다.

**메뉴 순서 바꾸기**
- 모든 html에서 메뉴 줄의 순서를 똑같이 바꿉니다.
- 홈 썸네일 순서는 각 썸네일의 `data-order="숫자"`로 정해집니다. 작은 숫자가 먼저(왼쪽 위) 옵니다.

## 7. 다른 컴퓨터로 옮기기

**방법 A — 폴더째 복사 (가장 간단)**
- 이 `teddictive-site` 폴더를 통째로 USB, 클라우드, AirDrop 등으로 옮기면 됩니다.
- 숨김 폴더 `.git`까지 함께 옮겨지므로, 옮긴 컴퓨터에서도 바로 올리기를 할 수 있습니다.
- 압축해서 보내도 됩니다(Finder에서 폴더 우클릭 → 압축).

**방법 B — GitHub에서 받기 (어느 컴퓨터에서나)**
```
git clone https://github.com/teddictive/teddictive.github.io.git teddictive-site
```
- 이 방법으로는 `_source/`(원본 백업)와 `새페이지/`(재료 폴더)는 받아지지 않습니다. 사이트 자체는 전부 받아집니다.

**새 컴퓨터에서 필요한 것**
- **macOS**: 미리보기와 페이지 만들기용 `python3`가 필요합니다. 터미널에 `python3 --version`을 입력했을 때 설치 창이 뜨면 설치하세요. 올리기용 `git`도 같이 설치됩니다.
- **GitHub 로그인**: 처음 올릴 때 한 번 필요합니다. 터미널에서 `gh auth login`을 쓰거나(GitHub CLI 설치 필요), git이 묻는 창에 GitHub 계정으로 로그인하세요.
- **Windows**: `.command` 파일은 맥 전용입니다. 대신 폴더에서 `python -m http.server 8770`(미리보기), `python tools/add_page.py 새페이지/폴더`(페이지 만들기), `git add -A && git commit -m "수정" && git push`(올리기)를 쓰세요.

## 8. 도메인·호스팅 정보 (참고)

- 도메인 `teddictive.com`: **Squarespace Domains**에서 관리합니다. DNS는 GitHub용 A 레코드 4개(185.199.108~111.153)와 `www` → `teddictive.github.io` CNAME입니다.
  - 도메인 갱신(연 1회 결제)을 잊지 마세요. 끊기면 teddictive.com이 열리지 않습니다. 그때는 저장소 Settings → Pages에서 Custom domain을 지우면 `teddictive.github.io`로 다시 열립니다.
- 호스팅: GitHub Pages(무료, 공개 저장소). HTTPS 인증서는 자동으로 갱신됩니다.
- `_source/build.py`는 2026-11-04에 받아 둔 Cargo 원본 데이터로 html을 **처음 상태로 다시 만드는** 스크립트입니다. 실행하면 그동안 고친 내용과 새로 만든 페이지가 모두 덮어써지니, 평소에는 쓰지 마세요.
